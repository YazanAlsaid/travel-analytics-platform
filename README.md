# Travel Analytics Platform

Cloud based travel analytics and ETL platform using Spring Boot, React, PostgreSQL and Python.

The platform processes travel-related data from multiple sources, stores it in a centralized database, and provides analytics dashboards and REST APIs for business insights.

## Features

- ETL pipeline with Python
- PostgreSQL relational database
- Spring Boot REST API
- React analytics dashboard
- Travel booking analytics
- SQL reporting and aggregation
- Modular architecture
- Cloud ready system design

## Technologies

| Layer    |   Technology      |
|----------|-------------------|
| Backend  |   Spring Boot     |
| Frontend |   React           |
| Database |   PostgreSQL      |
| ETL	   |   Python          |
| APIs	   |   REST            | 
| Analytics|   Jupyter Notebook|
| Containerization |	Docker |
| Version Control |	Git/GitHub |

## Main Goals

- Build a centralized travel analytics system
- Process and transform travel data
- Provide analytics APIs
- Visualize business insights
- Demonstrate modern data engineering concepts
